One sentence, written only with words a traveler from 1800 would already know, explaining the modern internet: a web of thin wires that lets any soul on earth send words, pictures, and songs to any other in the blink of an eye, as if every post office and library stood at your door.

## Run it

```sh
python3 main.py
```

It writes the sentence to `/output/entry.txt` (178 characters, one sentence).
